## 4. 设计原则（Principles）

1. **层级分工**：块级压缩（M 层）"删旧存新"（上下文看不见）+ 笔记压缩"折叠留痕"（上下文看得见）+ 工具表"算法即时止损"——三层互不替代，重叠由触发条件错开（M 层按 token 跨层、笔记按 0.85 窗口、工具表按条数 20）。
2. **配对的代价由折叠范围承担**：工具表折叠宁多删（整批）不破坏 wire 配对——孤儿 tool_call 是 provider 400 级事故，批内小结果随行进表是安全价。
3. **估算只在无 usage 处存在**：有 usage 一律真实计数（B3 + 跨 run 闭包传递）；估算（CJK 感知）只在无 usage provider / 请求前场景兜底。
4. **盲区如实上报**：笔记折叠丢弃的 user 消息（head/tail 之外）与 transcript 截断的行数都告知 LLM——不假装完整（KimiCode droppedCount 同纪律）。
5. **持久会话的落盘是快照不是日志**：每次 run 后全量重写（原子 tmp→rename + .bak），加载容忍截断尾行——比 append 日志简单且崩溃后自洽。
