## 背景

当前生产系统提示词（`static-prompt.ts` 的 `FULL_PROMPT_TEMPLATE`）有一处关键缺口：
- 没有解释 **databus 的多智能体协调语义**（主代理如何与子代理通过 databus 配合，避免重复工作、协调文件修改、了解进度）
- 没有给出 **压缩信封（CuratedMemory block）的实际格式** 和 **11 字段的填写指南**（尤其 `working_state` 的 5 个子字段）
- 没有 **ARCHITECTURE.md / MEMORY.md 的维护纪律**（何时创建、何时更新、格式、原则）
- 没有说明 **M0/M1/M2/M3 各层 LLM 实际看到什么**

`working-agent.md`（`src/im/prompts/working-agent.md`）这些内容都存在，但它不在生产注入路径上。生产路径用 `buildStaticPrompt()`（`static-prompt.ts` + `section-builder.ts`），不读 `working-agent.md`。
