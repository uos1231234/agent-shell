## 1. 约束（9 段约束，违反即错）

1. **SignalGate 三通道绝不混用**（ADR-026，`src/signals/types.ts:7-12`）：出站 emit/on、请求 request/resolve（300s fail-closed）、入站 command。CLI 是 gate 的第二个消费者——**B 形态下 gate 仍是唯一中转**（webapp 走 WS、CLI 进程内直连同一接口 `SignalGate`，`src/signals/types.ts:277-294`）。
2. **零 harness 改动**：本计划不新增任何 GateSignal/GateCommand/GateRequest 成员；不改 loop/状态机（v0.20 之后唯一允许的 loop 改动先例是 ToolTurn.toolName，本计划无此需求）。CLI 零新出站信号——产物行等全部是视图层投影（v0.24 P0 纪律，`c4c4260`）。
3. **UI 纯自研**（v0.22 拍板⑤精神，`e9b90d2`）：终端渲染器/编辑器/markdown 全部自研，**零新 npm 依赖**（库核心零依赖纪律延伸到 cli/——ts 源码引用走 `import type` 的 tsconfig paths 模式，与 webapp 相同）。
4. **工作区是权限边界**（`52315b1`）：CLI 会话创建必须携带 workDir，无 workDir 拒绝创建；doors（sensitive-path/dangerous-command/write-approval）全套注册，审批 fail-closed 300s。✅G5：恢复/resume 会话时校验该会话 workDir 与当前 CLI workdir 一致，不符拒绝并提示 `cd <dir>`（KimiCode 同款；session.list 返回 SessionInfo.workDir，零成本）。
5. **v0.25 装配事实不可回退**（`007ac91`）：装配依赖链顺序固定——registry → MCP/skills 注册 → subAgentRegistry（settings.json 开关产物 policy）→ rebindRoot → mailbox（带树）→ systemAgents → registerSystemAgentTools → exposedToolRefs（**同源双喂** buildStaticPrompt + buildLoopOptions，`examples/web-host.ts:370`）→ buildStaticPrompt。Wave 0 抽取必须整链搬移，顺序不变。
6. **record_m3_summary 永不进暴露清单**（v0.25 计划约束 4，`web-host.ts:370` 的 filter）。
7. **系统提示词用官方中文模板资产**（v0.19 接线教训，`e9b90d2`）：`buildStaticPrompt`（src/im/prompt/section-builder.ts），不许装配层手写占位。
8. **mock LLM 逻辑随装配一起进 src/host**（[已验证]：`createMockStreamChat` 现内联在 `examples/web-host.ts:117-142`，src/ 下无 mock——Wave 0 必须把它作为装配的一部分搬进 `src/host/mock.ts`，web-host 与 CLI 共用；否则"CLI 无 ARK_KEY 走 mock"不成立）。
9. ✅G1 **输入子系统参考 pi-tui editor 形态自研、零新依赖**（用户拍板完整档）：kill-ring + 多层 undo/redo + 词导航（CJK 特判，pi-tui 有 CJK-safe 处理先例）+ paste bursts。**中文 IME 是最大未知**——Wave 1 前置半天 spike 验证本机 Windows Terminal raw mode + IME 组合；失败则按 spike 结论记入 §7 并显式降级（诚实度：不假装能 IME）。

## 4. 设计原则（本计划特定的取舍，评审后修订）

1. **装配抽取 = 纯搬移，不借机重构**。Wave 0 唯一目标是 `src/host/assembly.ts` 与 `examples/web-host.ts` 行为逐字节等价（同一输入产生同一日志/端口/token 行为）；web-host 剩下 arg 解析 + HTTP server + main。重构冲动全部拒绝。
2. **渲染器/编辑器抄形态不抄代码**。pi-tui 的 `render(width): string[]` + 行级 diff + 字符串引用复用是被验证的最小正确模型（[已读未验]，代理逐文件核实），自研实现约 300 行。**编辑器（用户拍板完整档）** 参考 pi-tui `editor.ts`/`kill-ring.ts`/`undo-stack.ts`/`word-navigation.ts` 的公开行为自研（约 600-800 行，最大单件），CJK 词导航特判。
3. **命令表 = 元数据注册处一处事实源**。name/aliases/description/availability/argumentHint 全在一个 const 数组里，help 面板、**Tab 补全（✅P1-1，命令名 `/前缀` 过滤几十行；文件 mention 补全不做）**、分发 switch 三者都从它派生（KimiCode registry.ts 模式）；handler 按域分文件。
4. **命令文本永不进模型历史**；有会话副作用的命令只通过既有 GateCommand 产生副作用（KimiCode 纪律：command 输出 UI-only）。
5. **history 恢复走同一渲染路径**：session.history → 与实时信号同一 reducer/组件渲染（KimiCode session-replay 原则）。**MVP 先全量 hydrate（与 webapp 一致），bounded replay（尾部 N 回合）标注 v0.27 候选**（加 limit 属 harness 改动，违反约束 2）。
6. ✅G2 **输入态机四态 + idle 本地判定**：editor / approval / ask_user / picker。idle = !streaming && !approvalPending && !compacting（streaming = user.prompt 发出到 turn.end；审批挂起是独立态，不算 idle 也不算 streaming）。阻塞命令拒绝时**输入文本还原**（KimiCode restoreInputText 细节）。审批并发**队列化**（✅P1-2）：请求排队、一屏一个，会话切换 cancelAll，UI 失败兜底 cancelled（loop 不悬挂）。
7. ✅G6 **会话视图按 sessionId 分片**：gate 订阅全局 `on('*')`，SessionView 内部 `Map<sessionId, View>`，渲染只跟 activeSessionId；**切会话只切视图，在途回合后台继续**（B 形态进程内 runPrompt 异步、多会话并存，不打断）。
8. ✅G3/G4 **终端基本功三件**：raw mode 恢复兜底（`TuiScreen.stop()` 幂等 + process.on uncaughtException/unhandledRejection/SIGINT → 恢复 + 退出 + finally 兜底）；resize full redraw（`process.stdout.on('resize')`，Windows 无 SIGWINCH）；退出必经恢复。
9. ✅G5 **workDir 校验**：/resume 与 /sessions 选中会话时校验 workDir === 当前 CLI workdir，不符拒绝 + 提示 `cd <dir>`（呼应 §1.4）。
10. ✅G1 **IME spike 前置**：Wave 1 开工先做半天 spike，中文输入验证通过才按完整编辑器实现，失败记录降级路径。
11. **MVP 明确拒绝**：/compact /fork /undo /goal（宿主 driveCoordinator 仍 noop）、/model /provider 热切换（providers.json 重启生效是 v0.25 拍板）、/settings 面板、**skill:<name> 触发式命令**（技能已预注入系统提示词，普通 prompt 即用；做成命令需 harness 侧 activateSkill 契约 → v0.27，约束 2）、/plugin: 动态命令命名空间（无插件系统）、**/title**（gate 契约无 session.rename，砍掉有理由非遗漏）、bounded history（见原则 5）。
