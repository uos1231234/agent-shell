## 2. 实现分块

### 2.1 Playwright MCP 注册（默认配置）

**位置**：MCP server 默认配置（agent-shell 是独立 harness，默认注册）。

```json
{
  "name": "playwright",
  "transport": "stdio",
  "command": "npx",
  "args": ["-y", "@playwright/mcp@latest",
           "--caps=vision", "--image-responses=allow"]
}
```

**关键 flag**：
- `--caps=vision` → 启用坐标点击工具（browser_mouse_click_xy 等），视觉模型可直接按截图坐标操作
- `--image-responses=allow` → 截图作为 image content 返回给多模态模型
- `--isolated` → 每次会话隔离 profile（默认）
- 可选 `--cdp-endpoint ws://localhost:9222` → 连接用户真实浏览器（带登录态，等同 Kimi WebBridge 效果，无需装扩展）

### 2.2 open_url 系统工具

**功能**：在用户默认浏览器中打开 URL（AtomCode `open_file` 的 `open_url` 分支模式）。
**跨平台**：macOS `open` / Linux `xdg-open` / Windows `explorer`（避免 cmd 解析 URL 元字符）。
**安全**：仅 http/https scheme；headless/SSH 环境拒绝。

### 2.3 视觉链路（用户核心场景）

**缺口**：agent-shell 协议层目前**完全不支持图片**（无 image_url / vision / base64）。

**需要新增**：

1. **protocol 层 image content 支持**（OpenAI 格式）：
   ```typescript
   // ChatMessage content 支持部分：
   { type: 'text', text: '...' }
   { type: 'image_url', image_url: { url: 'data:image/png;base64,...' } }
   ```

2. **read_media 工具**（仿 AtomCode `read_file` vision 分支 + Kimi `ReadMediaFile`）：
   - 读图片文件 → base64 → 返回 `{ type: 'image_url', ... }` 给模型
   - 大小限制（≤4MB），非图片 → 报错
   - 可选 region 裁剪 / full_resolution（v2，先做基础版）

3. **视觉链路闭环**：
   ```
   模型调 browser_take_screenshot → 返回文件路径
   → 模型调 read_media(路径) → base64 image_url
   → 模型"看到"网页截图 → 视觉理解 → 给用户分析/修改建议
   ```

### 2.4 工具注册

`createBuiltinTools` 新增 2 个工具：
| 工具 | 类别 | 并发 | 功能 |
|---|---|---|---|
| `open_url` | command | 3 | 系统默认浏览器打开 URL |
| `read_media` | read | 5 | 读图 base64 喂视觉模型 |

## 5. 安全模型

| 风险 | 防护 |
|---|---|
| 打开恶意 URL | 用户默认浏览器沙箱；http/https scheme 白名单 |
| headless 打开 URL | 检测并拒绝，提示手动复制 |
| 读敏感图片 | read_media 走 resolvePathForRead（cwd 内）+ 不读 .env 等（敏感文件检测） |
| MCP 浏览器滥用 | 走 SubAgentToolPolicy；子代理默认不继承浏览器工具 |
| 截图文件堆积 | session 级临时目录，session 结束清理 |

---

## 6. 已知约束

- Playwright MCP 首次启动需下载浏览器二进制（~200MB），冷启动较慢
- `--image-responses=allow` 依赖模型支持多模态；文本模型需 vision_preprocessor 降级（v2，仿 AtomCode）
- `--cdp-endpoint` 连接真实浏览器需要用户手动启动 Chrome with remote debugging
