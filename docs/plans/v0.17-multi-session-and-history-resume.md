## 0. 功能定位

**一句话**：让一个**会话 UUID 同源贯穿所有机制**——security 权限、databus、子代理树 databus、压缩梯度（state-line）——并提供多会话窗口（`SessionManager` 创建/列出/切换）+ 历史会话恢复（按压缩梯度恢复，不重新压缩原始信息）。

**解决什么问题**：
1. 之前 `ConversationMemory`/`Databus` 纯内存，进程退出即丢失，无法恢复历史会话
2. 之前 databus 无 session 维度，多会话共享 registry 时 bus 归属不明
3. 之前子代理树 `AgentTree` 无 sessionId，own/family bus 无法追溯到会话
4. 之前 state-line 全局单命名空间，无法区分多会话的压缩梯度

**不做什么**（边界）：
- 不做会话级 `ToolRegistry`（共享 registry 不变，databus 靠 `SessionBusRegistry` 按 session 隔离）
- 不做会话窗口 UI（前端在 宿主应用仓库，agent-shell 只提供 `SessionManager` API）
- 不迁移旧全局 `~/.databus/state/`（向后兼容，新会话走 `~/.databus/sessions/`）
- 不改 state-line 内部 schema（`appendJsonl`/`appendStamp`/`createStateLine` 全部复用）

## 1. 约束（N 条硬约束，违反即不合格）

1. **session 与 security 机制解耦**：`SessionBusRegistry` 镜像 `SecurityRouter` 的生命周期形状（`Map<SessionId, ...>` + getOrCreate/delete）但**不 import `src/security/*`**。两者只共享 sessionId 字符串值，不共享对象/类。grep 已证 `security/` 与 `im/session/` 零互相引用。`[用户拍板："借用不要重复做工，但把握尺度不要耦合"]`
2. **一个 UUID 同源**：`SessionManager.createSession` mint 一次 UUID，同时作为 securitySessionId、databus sessionId、AgentTree.sessionId、会话目录名、state-line databusPath。不重复 mint。`[用户拍板]`
3. **databus 独立落盘（需改 ADR-016 §9）**：`databus.jsonl` 显式写 tool turns，恢复直接读。ADR-016 §9 "No cross-session databus persistence" 修订为"databus 可落盘为会话投影副本（snapshot），StateLine 仍是跨会话权威"。`[用户拍板]`
4. **快照 3 天 TTL**：`conversation.jsonl` + `databus.jsonl` 是"可重建副本"，默认保留 3 天（`pruneExpiredSnapshots()` 清理）。**StateLine 梯度永不清理**（不吞噬用户存储）。`[用户拍板]`
5. **恢复不重新压缩**：恢复的 ConversationMemory 只含活跃尾部（已压缩 turns 被 raw-archive.sourceTurnIds 过滤），driveCoordinator 只在活跃尾部找块，不触碰已落盘梯度。`[设计决策]`
6. **向后兼容**：`Databus` 的 `sessionId` 为可选构造参数，`new Databus()` 无参仍工作；`AgentTree` 的 `sessionId` 可选；`IMLoopOptions.persistTurn` 可选（未配置纯内存，行为不变）。`[已验证: 现有测试未破坏]`
7. **loop 的 MultiDatabus 泄漏修复**：ctxDatabus 组装从 while 循环内提到循环外创建一次，loop 结束 try/finally close()——修复每轮 `new MultiDatabus` 不 close 的泄漏。`[已验证]`

## 3. 架构信息

### 会话目录布局

```
~/.databus/sessions/
├── <sessionId-UUID>/
│   ├── session.json            # 元数据 (id/title/workingAgentId/createdAt/lastActiveAt/turnCount/layer/snapshotExpired)
│   ├── conversation.jsonl      # 完整 turns（3 天 TTL 快照）
│   ├── databus.jsonl           # 仅 tool turns（3 天 TTL 快照，databus 显式落盘）
│   └── state/                  # per-session state-line 梯度（长期，不清理）
│       ├── curatedMemory.jsonl # M1/M2 压缩摘要
│       ├── raw-archive.jsonl   # 被驱逐原始块 (summaryStamp↔sourceTurnIds)
│       ├── index.jsonl         # M3 摘要
│       └── stamps.jsonl
```

### 数据流（恢复流程）

```
openSession(id):
  read session.json → 验证存在
  read conversation.jsonl → allTurns
  read databus.jsonl → allToolTurns
  read state/raw-archive.jsonl → evictedIds = union(sourceTurnIds)
  activeTurns = allTurns.filter(!evictedIds)        # 活跃尾部
  activeToolTurns = allToolTurns.filter(!evictedIds)
  ConversationMemory = append(activeTurns)
  Databus = new Databus({ sessionId }) + append(activeToolTurns)
  StateLine = createStateLine({ databusPath: sessionDir })   # 梯度自动注入
  SessionBusRegistry.getOrCreateSession(sessionId) → { own, family }
  SubAgentRegistry = new SubAgentRegistry({ sessionId })     # 树绑 UUID
  DriveCoordinator = compression ? createDriveCoordinator(...) : createNoopDriveCoordinator()
  → SessionHandle → buildLoopOptions(base) → runIMLoop
```

### 会话 UUID 同源（核心一行）

```
SessionManager.createSession:
  sessionId = randomUUID()
  → 写 session.json
  → new Databus({ sessionId })
  → new SubAgentRegistry({ sessionId })      # → AgentTree({ sessionId })
  → createStateLine({ databusPath: <dir>/<sessionId> })
  → buildLoopOptions 里 sessionId 注入 IMLoopOptions.sessionId
  → registry.execute → SecurityRouter 用同一 sessionId
```

## 4. 设计原则

1. **解耦优先于复用**：`SessionBusRegistry` 与 `SecurityRouter` 同构但不合并——security 与 databus 是两个关注点，合并会引入 security→im 的强耦合，阻碍升级。只共享 UUID 字符串值。
2. **databus 落盘是"投影副本"而非 canonical**：ADR-016 §2.1 "Databus never becomes the ordering authority" 不变；`databus.jsonl` 只是会话投影的可重建副本，恢复时仍以 ConversationMemory 为顺序权威。
3. **TTL 保护用户存储**：快照（conversation + databus）默认 3 天，过期自动清理；梯度（StateLine）永不清理——因为梯度是压缩产物，体积小且有跨会话检索价值。
4. **恢复不重算**：已压缩 turns 被 raw-archive 过滤掉，恢复后不重新压缩；driveCoordinator 只在活跃尾部找块，梯度保持原样。
5. **向后兼容**：所有新增字段可选，未配置时行为与 v0.16 完全一致（纯内存、无 session 归属）。

## 7. 决策信息

**已决定**：
- `[用户拍板]` 会话存储：每会话独立目录 `~/.databus/sessions/<UUID>/`
- `[用户拍板]` 尾部持久化：每轮 append 到 conversation.jsonl（崩溃安全）
- `[用户拍板]` databus：SessionBusRegistry + **显式落盘**（databus.jsonl），需改 ADR-016 §9
- `[用户拍板]` 快照 3 天 TTL（不吞噬存储）
- `[用户拍板]` 子代理树：AgentTree 绑 sessionId
- `[用户拍板]` 借用 security 机制但不耦合：仅共享 UUID 字符串值
