# v0.19 — 提示词工程 + 可观测性

> Depends on: v0.18 已实现（渐进式工具披露，1487 tests 绿）
> Blocks: 无（独立功能）
> Status: 计划中
> ADR: ADR-024

---

## §0 总览

4 个特性，5 个批次，每批次 5–8 个子代理并行。

```
Batch 1: 类型定义（零依赖，纯 type/interface）          ← 所有后续批次的前置
Batch 2: 分层配置注入（prompt-layers + prompt-loader）    ← 依赖 Batch 1
Batch 3: 系统提示词段落化（prompt-sections）              ← 依赖 Batch 1
Batch 4: Auto Memory 系统（auto-memory + memory tools）  ← 依赖 Batch 1
Batch 5: 通用事件钩子（hook-system）                      ← 依赖 Batch 1
```

每个子代理的约束格式：
```
- 输入：依赖哪些已有文件/类型
- 修改：精确到文件路径和函数名
- 输出：新增/修改的文件 + 新增测试
- 边界：不碰哪些文件
- 测试：新增多少个 test case
```
